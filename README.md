# Cloud services for robot simulation

Seminar project for the course **SJK005 – Cloud Computing**.

The project explores how to simulate robots in the cloud without needing powerful hardware on your own laptop. It covers ready-made online workspaces (The Construct, Webots cloud), self-deployed simulators (Unity, MuJoCo Playground, Genesis), NVIDIA's cloud infrastructure (Brev, Omniverse Cloud, OSMO, Isaac Sim / Isaac Lab and Cosmos) and a live demo in which a PC with an NVIDIA GPU is shared through the browser with Selkies, running Gazebo and ROS 2 over Zenoh.
